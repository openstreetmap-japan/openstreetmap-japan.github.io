# OpenStreetMap 21th Birthday
2004年に始まったOpenStreetMapプロジェクト。
世界地図を世界のみんなで書いて共有する壮大なプロジェクトも開始されて21年もの歳月が経ちました。

# お誕生日会！
まぁ、そういった訳で、お誕生日会を開きます！
ぜひ、OpenStreetMapの21歳をお祝いに来てください！
