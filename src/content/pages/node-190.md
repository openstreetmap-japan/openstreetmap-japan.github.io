2013/02/11 - 2013/02/25
OpenStreetMap (OSM)の世界で起きているあらゆる出来事の要約です。
<!--break-->
<ul>
<li>State of the Map 2013カンファレンスの次回開催が、<a href="http://blog.osmfoundation.org/2013/02/16/state-of-the-map-2013-birmingham/" target="_blank">9月6−8日、バーミンガム(英)に決定</a>しました。事前参加登録は <a href="http://lanyrd.com/2013/sotm2013/" target="_blank">Lanyrd</a> で既に開始されています</li>
<li>2013年版の新しい"<a href="http://bestofosm.org/" target="_blank">Best of OSM</a>"ポスターが完成しました。ポスターは<a href="http://bestofosm.org/poster/" target="_blank">こちらのページ</a>に掲載、詳解のウェブページは<a href="http://bestofosm.org/" target="_blank">こちらです</a>。</li>
<li><a href="http://lists.openstreetmap.org/pipermail/talk/2013-February/066202.html" target="_blank">Google Summer of Code 2013</a>のプロジェクトアイデアを募集中です。</li>
<li>OSMプロジェクトに<a href="http://blog.osmfoundation.org/2013/02/25/two-more-new-tile-servers/" target="_blank">新しくタイルサーバが2つ追加</a>されました。</li>
<li>HOTプロジェクトでは Kunduz のマッピングで<a href="http://lists.openstreetmap.org/pipermail/hot/2013-February/002853.html" target="_blank">協力者を募集</a>しています！ また、マリ共和国の<a href="http://www.openstreetmap.org/user/AndrewBuck/diary/18643" target="_blank">マッピングのために新しいツールが導入</a>されました。その他HOT情報: Stephane Henriodさんによる、EUROSHA活動に関するブログ投稿は<a href="http://hot.openstreetmap.org/projects/eurosha_0" target="_blank">こちらから</a>。記事へのリンクは<a href="http://www.un-spider.org/about-us/news/en/6462/2013-02-20t115300/hot-demonstrating-usefulness-spatial-data-partners" target="_blank">UN-Spiderのブログのニュースページ</a>から辿ることもできます。</li>
<li><a href="http://www.flickr.com/photos/omnitarian/8466817332/sizes/o/in/photostream/" target="_blank">OSMにおける歴史的瞬間</a>の画像が Martin Elmarさんによって作成されました</li>
<li>OSM財団は2012年、duckdukgoから<a href="http://duckduckgo.tumblr.com/post/44000299625/duckduckgo-foss-donations-2012" target="_blank">5000ドルの寄付を受けました</a>。ありがとうございます！</li>
<li>再掲情報ですが、OSM, Google Maps, Nokia,そしてYandexの<a href="http://mc.bbbike.org/mc/?lon=60.36536&lat=54.97777&zoom=12&num=4&mt0=mapnik&mt1=google-map&mt2=nokia-map&mt3=yandex-map" target="_blank">地図比較ページ</a>。今回はチェリャビンスクです(隕石の落下が起きた場所)。</li>
<li>OSMエディタ Potlatch2の現在の状況についてのニュースはいかがでしょう？ Richard Fairhurstさんによる<a href="http://lists.openstreetmap.org/pipermail/potlatch-dev/2013-February/001964.html" target="_blank">報告です</a>。</li>
<li>Mikel Maronさんによるブログ投稿、<a href="http://www.openstreetmap.org/user/mikelmaron/diary/18630" target="_blank">地域に根づいたOSMマッパーの存在と不在について</a>。</li>
<li>Simon Rogersさんによる、CartoDBとOSMデータを利用した隕石落下記録の地図表示<a href="http://vimeo.com/59791629" target="_blank">チュートリアルビデオが公開</a>されました。</li>
<li><a href="http://mike.teczno.com/notes/elephants-osm-hadoop.html" target="_blank">OSMデータを Hadoopで処理する方法</a>について、Michael Migurskiさんの記事が公開されました。</li>
<li>カールスルーエ(独)の Hackweekend で、Andiさんと Jochenさんによって、新しい生成法による <a href="http://blog.jochentopf.com/2013-02-25-using-taginfo-to-create-map-feature-tables.html" target="_blank">Map Feature一覧表</a>の最初のプロトタイプができました。</li>
<li><a href="http://wiki.openstreetmap.org/wiki/Keypad-Mapper_3" target="_blank">Keypadmapper3</a>は、OSMプロジェクトで住所番号を入力する際に使える新しいツールです。Andoroid端末で利用できるよう開発されており、このアプリによる投稿結果は <a href="http://www.opencellids.org/" target="_blank">OpenCellIDs</a> プロジェクトにも同時投稿されます。</li>
<li>Maperitiveツールに関して、Igor Brejcさんによる新しいチュートリアル: <a href="http://braincrunch.tumblr.com/post/9921938947/maperitive-tutorial-a-hiking-web-map-in-ten-easy-steps" target="_blank">A Hiking Web Map in Ten Easy Steps が公開</a>されました。</li>
<li>Steve Coastさんによって、<a href="http://stevecoast.com/2013/02/13/my-first-kickstarter-project/" target="_blank">GPS-Art-Posterを作ろう</a>というクラウドファンディングプロジェクトがスタートしています。</li>

他にもなにかありましたら weekly.osm@googlemail.com までお知らせください。</li>
