原文：<a href="http://opengeodata.org/weekly-osm-summary-42">Weekly OSM Summary #42</a>

2012/4/23 - 2012/5/7

<a href="http://www.openstreetmap.org/">OpenStreetMap</a> (OSM)の世界で起きているあらゆる出来事の要約です。

<ul>
<li><a href="http://blog.osmfoundation.org/2012/04/26/license-change-still-ongoing/">ライセンス切り替え</a>とデータ再構築プロセスに関する最新ニュース。</li>
<li>OSM登録メンバー数は今や<a href="http://osmstats.altogetherlost.com/">60万</a>以上になりました。Pascalが最新のアクティブメンバーを表示する新しい<a href="http://hdyc.neis-one.org/newestosm.php">ウェブページ</a>を作りました。そのブログは<a href="http://neis-one.org/2012/04/where-are-the-new-openstreetmap-contributors/">こちら</a>。</li>
<li>Appleの新しいiPhotoは今やOSMプロジェクトをソースとして<a href="http://cl.ly/421B0u2r0u0J3o0I3e3s">表示</a>しています。</li>
<li><a href="http://stateofthemap.us/">State of the Map US</a> はポートランドで2012/10/13-14の間、開催されます。</li>
<li>今年のGoogle Summer of Codeに6つのOSMプロジェクトが<a href="http://lists.openstreetmap.org/pipermail/dev/2012-April/024878.html">採択されました</a>。</li>
<li>次の<a href="http://wherecamp.de/">Wherecamp Berlin</a> は6/22-23に開催されます。You can already register here.</li>
<li>"<a href="http://osm.gryph.de/2012/04/learn-from-wikipedia/">Wikipediaに学ぶ</a>" Frederik Rammによる新しいブログ。</li>
<li>Dan Stowell がどうやってOSMから<a href="http://mcld.co.uk/blog/blog.php?353">素敵なハンズアウト</a>を作ったかというブログ記事を投稿しました。</li>
<li>オックスフォードの<a href="http://www.transportparadise.co.uk/cyclemap/?zoom=2&lat=51.75381&lon=-1.25382&layers=B0">オンライン自転車マップ</a>がOSMデータを元に開発され、Maperitiveで作成されました。</li>
<li>"<a href="http://worstofosm.tumblr.com/">Worst Of OSM</a>" ウェブページにはOSMマッピングやインポートの試みのの失敗や載っています。</li>
<li>新しいHOT Technical Working Group が5/10(木)pm3時(GMT)に最初のIRCチャットを始めます。詳細は<a href="http://wiki.openstreetmap.org/wiki/Humanitarian_OSM_Team/Working_groups#Technical">こちら</a>。</li>
<li>"Waymarked Trails: Hiking" ウェブページが<a href="http://www.openstreetmap.org/user/Guttorm%20Flatab%C3%B8/diary/16804">7つの新しい言語</a>で使えるようになりました。</li>
<li>Maperitive の新バージョンではそれ自身のWalking papers を作れるようになりました。説明は<a href="http://braincrunch.tumblr.com/post/22434621619/maperitive-walking-papers-like-script">こちら</a>にあります。</li>
<li>Overpass API の新バージョンが使えるようになりました。すべての変更と新機能は<a href="http://wiki.openstreetmap.org/wiki/Overpass_API/versions#Overpass_API_v0.6.98">こちら</a>で。初めての方へ: <a href="http://wiki.openstreetmap.org/wiki/Overpass_API">Overpass API</a> は生のXMLエンコードされたOSMマップデータを提供する読み込み専用のAPIです。</li>
<li>Leafletオープンソースライブラリ向けの新しいプラグインではGPXやKMLオーバーレイやGoogleレイヤを表示する機能が追加されました。コードは<a href="https://github.com/shramov/leaflet-plugins">github</a>にあります。</li>
</ul>

何か漏れがありましたら weekly.osm@googlemail.com へお知らせください。
