■今回は協力を考えてくださってありがとうございます。
http://sinsai.info/
http://wiki.openstreetmap.org/wiki/2011_Sendai_earthquake_and_tsunami
にて、情報を案内しています。

Twitterではハッシュタグ <a href=http://twitter.com/#!/search?q=%23osmjp>#osmjp</a> で全般的な話題を扱っています。ご覧ください。

下のプロジェクトでは人手が足りませんので、協力をよろしくお願いいたします。
基本的にインターネット接続のできるパソコンでの作業になります。
<!--break-->
<strong>最初に</strong>

『できそうなこと（方面）を選んで、その先の各解説ペイジで作業を始めましょう』

<ul>
<li>
<strong>モデレータ方面（情報整理）</strong>
</li>
　こういう方に向いています「情報を欲しがっている人がすぐにたどり着けるようなタイトルに編集できる」
　スタートペイジ→ http://openstreetmap.jp/crisis/node/33

<li>
<strong>マッパー方面（地図作成）</strong>
</li>
　こういう方に向いています「衛星写真(システムで用意しています)をみてマウスでプチプチできる」
　<strong>絶対に他の地図を参照して入力しないでください!!</strong>
　　スタートペイジ→ http://openstreetmap.jp/crisis/node/20
　ツール二種について
　　 <a href=http://wiki.openstreetmap.org/wiki/Potlatch2>Potlatch2</a> → http://openstreetmap.jp/crisis/node/13
　　<a href=http://wiki.openstreetmap.org/wiki/JOSM>JOSM</a> → http://openstreetmap.jp/crisis/node/17
　他の人と編集が衝突しない様に、予め Twitter のハッシュタグ <a href=http://twitter.com/#!/search?q=%23osmeqjp>#osmeqjp</a> でつぶやいてから作業に入っていただけるとスムーズに出来ると思います。

<li>
<strong>翻訳方面（英文→和訳、和文→英訳）</strong>
</li>
　こういう方に向いています「英語と日本語がわかる」
　　スタートペイジ→ http://openstreetmap.jp/crisis/node/26 

<li>
<strong>サーバ方面</strong>
</li>
