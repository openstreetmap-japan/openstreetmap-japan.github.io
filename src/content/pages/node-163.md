2012/10/22 - 2012/11/5

<a href="http://www.openstreetmap.org/">OpenStreetMap</a> (OSM)の世界で起きているあらゆる出来事の要約です。

<ul>
<li><a href="http://blog.osmfoundation.org/2012/10/24/new-tile-server-in-moscow/" target="_blank">モスクワで新しいタイルサーバ</a>を提供してくれたYandex に感謝します。</li>
<li>OSM ユーザページでGravatar のユーザ画像をサポートするようになりました。この機能は<a href="http://api.osm.org/user/Pawe%C5%82%20Paprota/diary/17917" target="_blank">ユーザ設定</a>から有効化できます。</li>
<li>OpenStreetMap ウェブサイトとAPIは <a href="https://twitter.com/firefishy1/statuses/262998034860883969" target="_blank">IPv6 経由</a>で利用できるようになりました。</li>
<li>"Night of the Living Maps" に続いて新しいイベントを準備中です。"<a href="http://wiki.openstreetmap.org/wiki/Operation_cowboy" target="_blank">Operation Cowboy</a>" はグローバルなマッパソン イベントです。詳細は<a href="http://wiki.openstreetmap.org/wiki/Operation_cowboy" target="\lank">こちら</a>。</li>
<li>Richard Fairhurst と新しいOSM Javascript エディタ <a href="http://www.systemed.net/blog/index.php?post=24" target="_blank">iD</a>。Tom MacWright も関連記事を<a href="http://mapbox.com/osmdev/2012/10/25/diving-into-id/" target="_blank">ブログ</a>に書いています。</li>
<li>新しいHumanitarian OpenStreetMap Team (HOT) EUROSHA プロジェクトの最初の２週間についての<a href="http://lists.openstreetmap.org/pipermail/hot/2012-November/002312.html" target="_blank">記事</a>。</li>
<li>マップ上の<a href="http://a.tiles.mapbox.com/v3/saman.map-nzxr8zw8.html#3.00/44.96/-1.58" target="_blank">OSM データ密度</a>。</li>
<li>Frederik Ramm が"<a href="http://osm.gryph.de/2012/10/anti-business/" target="_blank">アンチ・ビジネス</a>" に関する主張を書いています。</li>
<li>“<a href="http://hdyc.neis-one.org/" target="_blank">How did you contribute to OpenStreetMap?</a>”のウェブページが更新されました。詳細は<a href="http://neis-one.org/2012/10/overhauling-hdyc/" target="_blank">ブログ記事</a>で。</li>
<li>Simon Poole が<a href="http://www.openstreetmap.org/user/SimonPoole/diary/17962" target="_blank">name の無い道路</a>の"live" レイヤーを作りました。</li>
<li>Martijn van Excel が<a href="https://oegeo.wordpress.com/2012/10/21/binders-full-of-tiger-deserts/" target="_blank">OSM US TIGER Deserts</a> についてのブログ記事を書きました。</li>
<li>MapRoulette が新しいことにチャレンジしています: すなわち<a href="http://oegeo.wordpress.com/2012/10/29/new-maproulette-challenge-connectivity-bugs/" target="_blank">接続のバグ</a>です。OSM Inspector ウェブサイトやその<a href="http://tools.geofabrik.de/osmi/debug.html?view=routing_non_eu&lon=-77.62641&lat=40.74052&zoom=6" target="_blank">ルーティングレイヤー</a>でもいくつか他のエラーとおぼしきソースを見つけることができます。</li>
<li>Tom MacWright が"<a href="http://macwright.org/2012/11/02/css-for-maps.html" target="_balnk">CSS For Maps</a>" についての記事を書きました。</li>
<li><a href="https://github.com/davidchiles/osm-poi-editor-iOS" target="_blank">iOS POI+</a> エディタと <a href="http://www.mysociety.org/2012/10/24/mysociety-launches-fixmystreet-platform-version-1-0-testers-and-translators-sought/" target="_blank">FixMyStreets</a> のソースコードがリリースされました。</li>
<li>Mike Niceman が<a href="http://lists.openstreetmap.org/pipermail/talk/2012-October/065020.html" target="_blank">OSM から GTFS</a> データに変換できるソースコードを公開しました。</li>
</ul>

何か漏れがありましたら weekly.osm@googlemail.com へお知らせください。
