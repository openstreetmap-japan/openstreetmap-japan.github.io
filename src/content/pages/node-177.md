2012/12/02 - 2012/12/16
<a href="http://www.openstreetmap.org/" target="_blank">OpenStreetMap</a> (OSM)の世界で起きているあらゆる出来事の要約です。

<ul>
<li>Andy Allanさんが<a href="http://lists.openstreetmap.org/pipermail/dev/2012-December/026256.html" target="_blank">OpenStreetMapの標準Mapnik</a>で表示されるスタイルをCartoCSSで再構築しました</li>
<li>新しいOSMエディタである iDの<a href="http://mapbox.com/osmdev/2012/12/06/designing-a-better-osm-editor/" target="_blank">初期デザインフェイズ</a>に関するブログ記事とデモバージョンは<a href="http://www.openstreetmap.org/user/lxbarth/diary/18236" target="_blank">こちらから</a>閲覧可能です</li>
<li>ロサンゼルス・タイムスは、ロサンゼルス消防局(LAFD)管理下の消防署の位置情報をOSMに寄与しました。詳しくは<a href="http://datadesk.latimes.com/posts/2012/12/lafd-stations-in-osm/" target="_blank">関連記事</a>と<a href="http://openfiremap.org/?zoom=11&lat=34.03297&lon=-118.17278&layers=B0000TF" target="_blank">OpenFireMap</a>を参照してみてください</li>
<li>"クラウドソース・マッピングを利用した災害リスク管理と緊急事態対応に関する国際会合"において発表された、すべてのドキュメントとスライドが公表されました。イベント自体のさらなる情報は<a href="http://www.un-spider.org/about-us/news/en/6317/2012-12-06t174500/international-meeting-crowdsource-mapping-successfully" target="_blank">こちらから</a>確認することができます</li>
<li>Harry Woodさんがブログ記事で、<a href="http://www.openstreetmap.org/user/Harry%20Wood/diary/18201" target="_blank">先日行われた London Hack-weekend</a>について投稿しました。たいへん素晴らしい写真ですw Harryさんの手による <a href="http://harrywood.co.uk/maps/uixapi/xapi.html" target="_blank">XAPI URLビルダー</a>は、今後 <a href="http://wiki.openstreetmap.org/wiki/Overpass_API" target="_blank">OverPass API</a>もサポートサポートします</li>
<li>Mapbox社によって<a href="http://mapbox.com/blog/mapbox-satellite/" target="_blank">新しい衛星写真レイヤ</a>が追加されました。OSMトレース用データとしてこの新しいデータをどのように使えばよいのか、<a href="http://mapbox.com/blog/open-aerial/" target="_blank">詳しい情報</a>は<a href="http://support.mapbox.com/discussions/general-questions/9924-using-satellite-images-for-osm-tracing" target="_blank">こちらから</a>参照できます</li>
<li>PostGISへOSMデータをインポートする際によく使われる <a href="http://pypi.python.org/pypi/imposm" target="_blank">"Imposm"</a>ですが、このたび PostGIS 2.0のサポートを開始しました</li>
<li><a href="http://lists.openstreetmap.org/pipermail/imports/2012-December/001615.html" target="_blank">"addressmerge"</a>の初版がリリースされました。このツールを使うことで、住所情報を登録する際に必要な手順として、既にOSMへ投入済みの住所情報との比較を容易に行うことができます</li>
<li>Frederik Rammさんのブログ投稿: <a href="http://osm.gryph.de/2012/12/1000-addresses/" target="_blank">your 1,000 house numbers</a> (住所情報1000個)、あなたはもう入力しましたか？</li>
<li>ロンドンの建物を<a href="http://tomholderness.wordpress.com/2012/12/12/3dlondon/" target="_blank">3Dマッピング</a>で可視化する方法、についてTo Holdernessさんのブログ投稿があります</li>
<li>3Dメガネに映写可能な <a href="http://osmbuildings.org/anaglyph3d/" target="_blank">OSM 3D建物データ</a></li>
<li>Geofabrik社による、地域ごとのPBF形式OSMデータへタイムスタンプ情報が追加されるようになりました。ファイルのヘッダ情報についての新情報は<a href="http://lists.openstreetmap.org/pipermail/dev/2012-December/026278.html" target="_blank">こちらを参照</a>してください</li>
<li>Vizrtは放送局向けに、OSMを使った<a href="http://www.vizrt.com/news/article18035.ece" target="_blank">世界の道路マップ</a>の提供を開始しました</li>
</ul>
	
他にもなにかありましたら weekly.osm@googlemail.com までお知らせください。
