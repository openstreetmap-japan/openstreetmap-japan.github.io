2012/12/16 - 2012/12/30

<a href="http://www.openstreetmap.org/" target="_blank">OpenStreetMap</a> (OSM)の世界で起きているあらゆる出来事の要約です。

<ul>
<li>次回開催予定の State of the Map(SotM) 2013について、開催地の募集が始まりました。開催地の提案は<a href="http://wiki.openstreetmap.org/wiki/State_Of_The_Map_2013/Call_for_venues" target="_blank">こちらから</a>お願いします。</li>
<li>OSMプロジェクトの新サーバが<a href="http://blog.osmfoundation.org/2012/12/18/new-tile-server-in-pau-france/" target="_blank">フランスに設置</a>されました。<a href="http://wiki.openstreetmap.org/wiki/Servers/Tile_CDN" target="_blank">Content Delivery Network (CDN)用のタイル画像の配信</a>を行います。</li>
<li>OSM USメーリングリストにて、OSMへの<a href="http://lists.openstreetmap.org/pipermail/talk-us/2012-December/thread.html#9966" target="_blank">データインポート</a>について議論がありました。どのような<a href="http://lists.openstreetmap.org/pipermail/osmf-talk/2012-December/001947.html" target="_blank">編集方針</a>のもとで行われるべきか、異なるスレッドにおいても議論されています</li>
<li>OSMの新しいエディタソフトが<a href="lists.openstreetmap.org/pipermail/dev/2012-December/026351.html" target="_blank">オンラインで</a>利用可能になりました。まだアルファ版です！</li>
<li>すべてのOSM開発者へ: あなたのコードは、<a href="lists.openstreetmap.org/pipermail/dev/2012-December/026354.html" target="_blank">ノードIDの64 bit化</a>に対応していますか？</li>
<li>overpass APIを利用して、<a href="http://lists.openstreetmap.org/pipermail/talk/2012-December/065459.html" target="_blank">分単位で住所番号情報が更新されるマップ</a>が、Ronald Olbrichtさんによって作成されました。ここを確認すれば、住所や番地情報が欠落しているのがどの場所なのかを見つけることが可能です。</li>
<li>英・ロンドンにおけるほぼ全ての幹線道と主要道について、<a href="http://www.openstreetmap.org/user/Amaroussi/diary/18270" target="_blank">街灯の有無がOSMに反映</a>されました。ITOの<a href="http://www.itoworld.com/map/69#fullscreen" target="_blank">道路照明マップ</a>で結果をみることができます。</li>
<li>OSMデータの素敵な使い方の一例: <a href="http://cartodb.github.com/cartodb.js/examples/TheHobbitLocations/" target="_blank">映画 Hobbit撮影地マップ</a></li>
<li><a href="http://mapbox.com/blog/trouble-with-geoportals/" target="_blank">Chris Herwig さんのブログ</a>に、Mapboxへ衛星写真レイヤーを作成して追加する際に遭遇したトラブルについての投稿がありました</li>
<li>多言語マッププロジェクトについて、Jochen Topfからの<a href="http://blog.jochentopf.com/2012-12-19-status-of-the-multilingual-maps-project.html" target="_blank">最終レポート</a>が報告されました</li>
<li>2人のOSM貢献者で競い合うゲーム <a href="http://osmfight.neis-one.org/" target="_blank">OSMFight</a> で、新たに2つのラウンドが追加されました</li>
<li>新しいバージョンの MapOSMaticが<a href="http://lists.nongnu.org/archive/html/maposmatic-dev/2012-12/msg00024.html" target="_blank">オンラインになりました</a>。<a href="http://dev.maposmatic.org/" target="_blank">MapOSMatic</a>では、OSMデータをもとに街の地図を作成することができます</li>
<li>BeWelcomeプロジェクトのウェブサイトで、<a href="http://www.bewelcome.org/blog/planetcruiser/1568" target="_blank">OSMの地図が使われています</a>。<a href="http://www.bewelcome.org/" target="_blank">BeWelcome</a>は異文化交流ネットワークで、宿泊や会合場所のやりとり、困ったときの互助を目的としています。ボランティアによって運営されているNPO団体です。</li>
<li>KortはOSMデータの改善に役立つ、新しいオープンソースの携帯ゲームです。まだ開発はテスト段階ですが、ゲームについてより詳しい情報が <a href="http://wiki.openstreetmap.org/wiki/Kort_App" target="_blank">OSM wiki</a>に掲載されています。</li>
<li>OSMに登録されている全ての消防署の位置をオンラインで確認できる地図がThomas Rupprecht さんによって作成されました。<a href="http://rfmtc.no-ip.org/osm/firemap/" target="_blank">デモページはこちら</a>で、<a href="https://github.com/Soldier-Boy/firemap/" target="_blank">ソースコードは github</a>に存在します。</li>
</li>
</ul>

他にもなにかありましたら weekly.osm@googlemail.com までお知らせください。
