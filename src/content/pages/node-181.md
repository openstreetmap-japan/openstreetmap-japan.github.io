2012/12/30 - 2013/01/13
OpenStreetMap (OSM)の世界で起きているあらゆる出来事の要約です。

<ul>
<li>2012年に行われたOSM編集記録が可視化された "<a href="http://vimeo.com/56374742" target="_blank">Year of Edits</a>"ビデオが<a href="http://vimeo.com/56374742" target="_blank">こちらで公開</a>されました。Derick Rethansさんありがとう！</li>
<li>ご存知かもしれませんが: 先週、OSMプロジェクトへの参加登録者数が <a href="http://opengeodata.org/1-million-openstreetmappers" target="_blank">1 000 000 人を突破</a>しました。オンライン記事として <a href="http://idealab.talkingpointsmemo.com/2013/01/openstreetmap-reaches-1-million-users-will-rival-google-maps-in-2-years.php" target="_blank">TPM</a> や <a href="http://futurezone.at/netzpolitik/13357-openstreetmap-hat-das-rennen-gewonnen.php" target="_blank">futurzone.at</a> (ドイツ語) で言及されており、また <a href="http://www.openstreetmap.org/user/Harry%20Wood/diary/18354" target="_blank">Harry Woodさん</a>や <a href="http://neis-one.org/2013/01/oooc/" target="_blank">Pascal Neisさん</a>のブログ(の最後のほう)にもさらに追加の内容があります。</li>
<li>OSM人道支援チーム(HOT)は、<a href="http://hot.openstreetmap.org/updates/2013-01-02_2012_was_hotcant_wait_for_2013" target="_blank">2012年の彼らの活動レビュー</a>、そして2013年の展望について記事を公開しています。さらに、Mapbox社からの支援が行われ、<a href="http://mapbox.com/blog/pansharpening-satellite-imagery-openstreetmap/" target="_blank">衛星写真のトレース</a>によるOSM編集がより簡単になりました。</li>
<li>トレース用データとして<a href="http://blog.osmfoundation.org/2013/01/01/new-aerial-imagery-south-africa/" target="_blank">OSMで利用できる航空写真</a>として、南アフリカの画像が利用可能になりました</li>
<li>数週間前のFrederik Rammさんがブログに、もし全てのマッパーが<a href="http://osm.gryph.de/2012/12/1000-addresses/" target="_blank">一人 1000個の住所番号</a>をOSMに登録したらどのようなことが起こるかを投稿しました。現在彼は、住所番号を入力したことのある<a href="http://lists.openstreetmap.org/pipermail/talk/2012-December/065490.html" target="_blank">アカウントの一覧</a>を作成しています。類似の情報はウエブページ "<a href="http://hdyc.neis-one.org/?woodpeck" target="_blank">How did you contribute to OpenStreetMap?</a>" でも確認することが可能です。</li>
<li>Dan Stowellさんの記事で、OSMデータを基にした "<a href="http://mcld.co.uk/blog/blog.php?379" target="_blank">イギリスとアイルランドのパブデータ可視化</a>"が公開されました</li>
<li>OSM Watchlistの新しい(ベータ)バージョンがPaweł Paprotaさんの手によってオンラインになりました。アナウンス文は<a href="http://lists.openstreetmap.org/pipermail/talk/2013-January/065556.html" target="_blank">こちらから</a>閲覧可能です</li>
<li>あなたが編集している地域で<a href="http://neis-one.org/2013/01/oooc/" target="_blank">他に編集を行なっている貢献者を視覚化</a>するウェブページを、Pascal Neisさんが作成しました</li>
<li>OSM Pushpinエディタが<a href="http://spatialnetworks.com/blog/2013/01/the-first-3-months-of-pushpin-and-openstreetmap/" target="_blank">どのくらい使われているか</a>の統計データ公開</li>
<li>"<a href="http://lists.openstreetmap.org/pipermail/talk/2013-January/065784.html" target="_blank">OSM contributor mark</a>"を定義しようという Alex Barthさんからの提案がありました。内容は OSM Talk メーリングリストで確認することができます。もちろん、さらなる議論はメーリングリストで可能です。</li>
<li>Mapbox社が提供する衛星写真がトレース用データとして、誰もがJOSMで使えるようになりました。アナウンス文は<a href="http://lists.openstreetmap.org/pipermail/josm-dev/2013-January/006425.html" target="_blank">こちらを参照</a>ください</li>
<li><a href="http://www.kickstarter.com/projects/903141699/leikr-the-new-danish-designed-gps-sports-watch" target="_blank">GPS腕時計を開発</a>するため、Kickstarterで新しいプロジェクトが立ち上がりました。2インチのディスプレイ付きでOSMの地図を表示することができます。</li>
<li>今後開催が予定されている OSM関連イベントはこちら:
        <li><a href="http://wiki.opendataday.org/Main_Page" target="_blank">Open Data Day: 2012/02/23</a></li>
        <li><a href="http://openstreetmap.fr/ag2013" target="_blank">State of the Map France: 2013/02/23 - 02/24</a></li>
        <li><a href="http://wiki.openstreetmap.org/wiki/London_Hack_Weekend_Feb_2013" target="_blank">OSM Hack Weekend London: 2013/02/02 - 02/03</a></li>
        <li><a href="http://wiki.openstreetmap.org/wiki/Karlsruhe_Hack_Weekend_February_2013" target="_blank">OSM Hack Weekend Karlsruhe: 2013/02/23 - 02/24</a></li>
</li>
</ul>
