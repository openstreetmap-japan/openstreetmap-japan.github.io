2012/8/27 - 2012/9/10

<a href="http://www.openstreetmap.org/">OpenStreetMap</a> (OSM)の世界で起きているあらゆる出来事の要約です。

<ul>
<li>OpenStreetMap はそのライセンスをODbL に切り替えました。公式なブログ記事は<a href="http://blog.osmfoundation.org/2012/09/06/your-first-odbl-planet">こちら</a>、最初のOSM Planet ダンプファイルは<a href="http://planet.openstreetmap.org/">こちら</a>。あなたのデータベースに順を追って再インポートしてください。</li>
<li><a href="http://blog.osmfoundation.org/2012/09/08/new-board-members-2/">新しく選出されたOSMF 理事会メンバー</a>に祝福を: Frederik Ramm, Henk Hoff そしてSimon Poole です。</li>
<li>東京で開催されたState of the map 2012 の<a href="http://wiki.openstreetmap.org/wiki/State_Of_The_Map_2012/Thursday">セッションの全記録</a>はOSM wiki内にあります。</li>
<li>ITO よりいくつかの素晴らしいビデオが公開されました。<a href="http://vimeo.com/48919759">日本でのこの5年間の編集の様子</a>と<a href="http://vimeo.com/49003594">全世界の2008-2011の4年間の編集の様子</a>です。</li>
<li>Christian Quest がOSMプロジェクト用に<a href="http://live.openstreetmap.fr/">編集状況をライブに表示する</a>とっても素敵なウェブページを作りました。また、JavaツールのOSMZmiany ではOSMデータベース内のあなたの<a href="http://wiki.openstreetmap.org/wiki/OSMZmiany">最新の更新</a>を見ることができます。</li>
<li>Dakar で開かれた<a href="http://hot.openstreetmap.org/updates/2012-08-28_the_osm_project_senegal_joining_tech_camp_dakar_30_31_august_2012">Tech Camp でのHOT</a>に関するブログ記事。また、HOTをその<a href="http://lists.openstreetmap.org/pipermail/hot/2012-August/002168.html">新しいウェブサイト</a>で支援することもできます。</li>
<li>Pascal Neis が"I Like OpenStreetMap" というOpenLayers のプラグインを公開しました。これを使うとユーザはOpenStreetMap 内のあるエリアの状況についての「好き」「嫌い」のフィードバックを残すことができます。詳細は<a href="http://ilike.openstreetmap.de/">こちら</a>と<a href="http://neis-one.org/2012/08/i-like-osm/">こちら</a>のブログ記事。</li>
<li>Martijn van Excel が改訂ボットが引き起こしたエラーを修正するための<a href="http://oegeo.wordpress.com/2012/08/29/remapathon/">素敵なツール</a>をいくつか作りました。<a href="http://lima.schaaltreinen.nl/remap/">こちらでお試しください</a>。</li>
<li><a href="http://wiki.openstreetmap.org/wiki/Karlsruhe_Hack_Weekend_October_2012">ドイツでの次のOSM Hack Weekend</a> が10月の最初の週末に計画されています。</li>
<li>Tom MacWright が"<a href="http://mapbox.com/blog/2012-08-28-running-maps/">Running Maps</a>" とその3D <a href="http://mapbox.com/demo/running/">デモ</a>に関するブログ記事を書きました。</li>
<li>高速なOSM Open Source Routing MachineのウェブページがLeaflet 0.4に<a href="http://map.project-osrm.org/">更新されました</a>。</li>
<li><a href="http://wiki.openstreetmap.org/wiki/Overpass_API/Augmented_Diffs">現在</a>Overpass API がAugmented Minute Diff(拡張詳細差分) ファイルを提供しています。あるエリアではOSMデータベースの更新にこれを使うことができます。</li>
<li>マッパーカードに興味ありますか？Richard Weait が<a href="http://lists.openstreetmap.org/pipermail/dev/2012-September/025578.html">いくつか</a>作りました。</li>
<li>wheelmap.org のウェブページが<a href="http://wheelmap.org/dashboard">新しいダッシュボード</a>で、障害やハンディキャップのある人にやさしい環境を提供しているいくつかの大都市エリア内の場所について統計や情報をいくつか表示できるようになりました。</li>
<li>Stamen Designs があなた自身のOSMプリントアウトを作れるサービスMap2Image を公開しました。お試しは<a href="http://maps.stamen.com/m2i/#toner/768:512/12/37.7749/-122.4347">こちら</a>。</li>
<li>Sage　コミュニティが作成した<a href="https://community.sagecrm.com/user_community/b/sage_crm_news/archive/2012/08/28/sage-crm-mapping-component-7.1.aspx">OSMモジュール</a>がSage CRM に追加されました。</li>

</ul>

何か漏れがありましたら weekly.osm@googlemail.com へお知らせください。
