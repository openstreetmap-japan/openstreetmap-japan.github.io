OpenStreetMap Japan のウェブサイトを刷新し、新しい基盤で公開しました。
これまで [openstreetmap.jp](https://openstreetmap.jp) で長らく Drupal 上で運用してきたコンテンツとイベント情報を、静的サイトジェネレーター [Astro](https://astro.build) ベースの新しいサイトに移行しています。表示の高速化や保守の簡素化、コミュニティ参加のしやすさを目指しています。

<h2>主な特徴</h2>

<ul>
<li>これまでのイベント情報、ガイドはほぼそのまま新サイトへ移行しています。</li>
<li>過去の <code>https://openstreetmap.jp/node/&lt;id&gt;</code> 形式の URL は、新サイトの <code>/node/&lt;id&gt;/</code> や <code>/events/&lt;id&gt;/</code> でも参照できるようにしています。</li>
<li>イベント一覧と地図表示、コミュニティ向けリンクを刷新しました。</li>
<li>RSS フィードを提供しています: <a href="/rss.xml">/rss.xml</a></li>
</ul>

<h2>ソースコードと貢献</h2>

新サイトはオープンソースとして GitHub で開発しています。
<ul>
<li>リポジトリ: <a href="https://github.com/openstreetmap-japan/openstreetmap-japan.github.io">openstreetmap-japan/openstreetmap-japan.github.io</a></li>
<li>記事の追加・誤字修正などの Pull Request を歓迎します。記事の書き方は README に記載しています。</li>
<li>サイトに関する不具合や提案は、Issue または <a href="https://discord.gg/pNuUM99kUX">OpenStreetMap Japan Discord</a> へお寄せください。</li>
</ul>
<h2>これから</h2>

旧サイトに残っているコンテンツの移行や、新規イベント情報の集約を順次進めていきます。OpenStreetMap Japan の活動を、引き続きどうぞよろしくお願いいたします。
